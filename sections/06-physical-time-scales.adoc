
[[physical-time-scale]]
== Physical time scale

=== General

Physical time scales are created and managed by time authorities.

Physical time scales can contain time modification records. For example, the UTC time scale
provides a list of leap seconds that adjusted UTC time since its inception.


[[physical-time-scale-types]]
=== Types of physical time scales

==== International physical time scales

International physical time scales are physical time scales that apply internationally
without regard to geolocation.

[example]
UTC and TAI are international physical time scales.


==== Official physical time scales

Official physical time scales are created by official physical time scale authorities
and international physical time scale authorities.


==== Unofficial physical time scales

Unofficial physical time scales can be created by any physical time scale authority.


=== Registration of physical time scales

The ISO 34100/AG is tasked with managing a list of physical time scales.

==== Physical time scale code

A code that represents the physical time scale.


==== ISO 3166 alpha-2-code

A code that represents the geographic applicability of the physical time scale.

[example]
UTC time applies globally with the code `aa`.


==== Internationally recognized short name

The internationally recognized short name that uniquely identifies the physical time scale.


==== Abbreviation

The identifiable abbreviation used for the physical time scale. This is optional.


==== Physical time scale authority code

A code that represents the physical time scale authority who manages this physical time scale.


==== Remarks

Any further notes.


==== Leap seconds

A record of positive or negative leap seconds applied to the physical time scale
at the described date.

[example]
UTC leap seconds are provided since its inception in 1972.

[example]
Leap seconds does not apply to the GMT physical time scale.


=== Code and identifier

==== Principles for inclusion in the list of physical time scales

===== List

The list of physical time scales in this document includes known
physical time scales from official sources.


===== Source of names

Names and abbreviations of physical time scales are obtained from the
physical time scale authorities or other official sources.


===== Overlaps

Some physical time scales cover areas that have also been coded separately where an interchange requirement justifies a separate code element; the entries are therefore not mutually exclusive.

[example]
`aa-utc` applies internationally.

[example]
`us-gps` applies to the United States.


===== Current status of names

Physical time scales listed in this document are intended to reflect the current situation, at the time of issue of the latest update of this document.



==== Principles for allocation of code elements

===== Relationship with names

Official physical time scale identifiers are in the following format:

[source]
----
[iso-3166-code]-[physical-time-scale-identifier]
----

[example]
`hk-utchk` for the UTC(Hong Kong) physical time scale managed by the Hong Kong Observatory.


The <<ISO3166-1>> private code point `AA` is used as a prefix
for international physical time scales.

[source]
----
aa-[physical-time-scale-identifier]
----

[example]
`aa-utc` for the UTC physical time scale managed by the BIPM.



The <<ISO3166-1>> private code point `ZZ` is used as a prefix
for all unofficial physical time scales.

In terms of coding, official physical time scale identifiers are in the
following format:

[source]
----
zz-[physical-time-scale-authority-identifier]-[physical-time-scale-identifier]
----

////
[example]
`zz-uco-lst` for the Lick Standard Time physical time scale managed by the University of California Observatories.
////


===== Construction of the alphabetic code

The following rules are to be adhered to for the assignment of the alphabetic code:

* The alphabetic code uses combinations, in upper case, of a maximum of 16 letters of the 26-character Latin alphabet with the "dash" (`-`).
//, allowing for close to $4^27$ combinations.

* To encourage descriptive and distinguishable alphabetic names, the minimum length of the physical time scale identifier without the <<ISO3166-1>> code is 3 letters.

* The specific code prefix of `XX` is reserved and is used as the prefix of user-assignable physical time scale codes.



===== User assigned code elements

If users need code elements to represent physical time scales not included in the physical time scale registry, the <<ISO3166-1>> code prefix of `XX` can be used, being a reserved code point `XX` for private user assignment.

The code length for the physical time scale identifier must be 3 or more letters.

Such physical time scale identifiers are in the following format:

[source]
----
xx-[physical-time-scale-authority-identifier]-[physical time scale-identifier]
----

////
[example]
`xx-unece-cet` is an example of a user-assigned private code for a physical time scale published by the UN/ECE.
////

NOTE: Users are advised that the above series of codes are not universals, those code elements are not compatible between different entities.


==== List of physical time scale and their code elements

The list of items composing the content of the country code is initially defined in <<annex-physical-time-scales>>.
Additional and new entries will be listed by the ISO 34100/AG.

Data attributes provided in the list is defined in <<ts-data-model>>.
