
[[physical-time-scale-authority]]
== Physical time scale authority

=== General

A physical time scale authority is a competent authority that creates,
publishes and/or manages definitions of physical time scales
and their changes.


=== Requirements of a physical time scale authority

A physical time scale authority must be competent.

==== Competency

A competent physical time scale authority is one that has standardized
processes surrounding the management of the physical time scales,
covering at least the following processes:

. Planning of physical time scales, including the process of designing and defining a physical time scale.
. Performing changes to physical time scales are well planned and executed in a manner that is considerate of physical time scale users.
. Public announcement and dissemination of its physical time scale.
. Authoritative announcement of current time under a physical time scale under its management.
. Allows a public review period for people affected by physical time scales under its management prior to enactment.


[[ts-authority-types]]
=== Types of physical time scale authorities

==== International physical time scale authorities

International physical time scale authorities are listed with the <<ISO3166-1>> code `AA`.

It is defined as a physical time scale authority that:

. operates under international scope; and
. whose decisions for physical time scale management are made with international participation.

[example]
The BIPM is an international physical time scale authority.


==== Official physical time scale authority

An official physical time scale authority is appointed by a local or
regional governmental body, whereas the authority for appointment
comes from a United Nations member state.

[example]
The US NIST with the code `us-nist`, publishes physical time scales that apply to the territory of United States.


==== Unofficial physical time scale authority

An unofficial physical time scale authority is a physical time scale authority
not appointed by a United Nations member state.
These authorities must be competent with regards to
physical time scale management and can publish physical time scales used by
communities.


=== Registration of physical time scale authorities

The ISO 34100/AG is tasked with managing a list of
physical time scale authorities.

=== Code and identifier


==== Principles for inclusion in the list of physical time scale authorities

===== List

The list of physical time scale authorities in this document includes known
authorities from regions consisting of <<ISO3166-1>> codes through
official sources.


===== Source of names

Names and abbreviations of physical time scales are obtained from the
physical time scale authorities or official sources.


===== Overlaps

Some physical time scale authorities cover areas that have also been coded separately where an interchange requirement justifies a separate code element; the entries are therefore not mutually exclusive.

[example]
The China National Time Service Center, with the code `cn-ntsc`, publishes physical time scales that contribute to the UTC time scale.

[example]
The Hong Kong Observatory with the code `hk-hko`, publishes physical time scales that contribute to the UTC time scale.


===== Current status of names

Physical time scale authorities listed in this document are intended to reflect the current situation, at the time of issue of the latest update of this document.



==== Principles for allocation of code elements

===== Relationship with names

The principle behind the alphabetic codes for physical time scale authorities is a visual association between the physical time scale authorities and their corresponding code elements.

In applying this principle, the code elements have generally been assigned on the basis of the abbreviated names of the physical time scale authorities, thus avoiding, wherever possible, any reflection of their political status.

===== Construction of the alphabetic code

The following rules are to be adhered to for the assignment of the alphabetic code:

* The alphabetic code uses combinations, in upper case, of a maximum of 10 letters of the 26-character Latin alphabet, allowing for
close to $4^26$ combinations.

* To encourage descriptive and distinguishable alphabetic names, the minimum length of an assigned code is 3 letters.

* The specific code of `xx` is reserved and is used as the prefix of user-assignable physical time scale authority codes.



===== User assigned code elements

If users need code elements to represent physical time scale authorities not included in the physical time scale authority registry, the code prefix of `xx` can be used, and the code length behind the prefix must be 3 or more letters.

[example]
`xx-unece` could be a user assignment of an internal physical time scale authority of UN/ECE.

NOTE: Users are advised that the above series of codes are not universals, those code elements are not compatible between different entities.


==== List of physical time scale authorities and their code elements

The list of items composing the content of the country code is initially defined in <<annex-physical-time-scale-authorities>>.
Additional and new entries will be listed by the ISO 34100/AG.

Data attributes provided in the list are defined in <<ts-authority-data-model>>.
